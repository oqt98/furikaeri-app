# furikaeri-app

テンプレ選択式の振り返りアプリです。  
自由記述だけに頼らず、**気分・カテゴリ・タグ・テンプレ**から振り返りを始められるようにしています。

---

## 📱 アプリ概要

このアプリは、日々の振り返りを**「続けやすくする」**ことを目的にしたスマホアプリです。

一般的な日記アプリのように、毎回ゼロから書くのではなく、

- テンプレを選ぶ
- 気分を選ぶ
- タグを選ぶ
- 必要な項目だけ入力する

という流れで、振り返りを始めやすくしています。

---

## ✨ コンセプト

- 何を書くか迷わない
- 気分から入れる
- あとで見返しやすい
- 続けやすさを重視する

このアプリの軸は、**「思考を補助する振り返り」**です。

---

## ✅ 現在できること

- テンプレ一覧から振り返り方法を選択
- ランダムでテンプレ選択
- 気分の選択
- カテゴリの選択（仕事 / プラベ）
- タグの選択
- テンプレに応じた入力欄の表示
- 振り返り内容の保存
- 履歴一覧の表示
