# 振り返りアプリ（仮称）

忙しい日でも短時間で記録でき、あとから見返して次の日の改善につなげられる軽量な振り返りアプリです。

「長い日記は続かない。でも何も残さないと毎日が流れてしまう」という感覚に対して、重すぎない入力と見返しやすさの両立を目指しています。

---

## コンセプト

このアプリは、次の3つを大切にしています。

- 軽いコストでさっと振り返れること
- あとから見返しやすいこと
- 日々を少しずつ改善していけること

### 想定ユーザー

忙しくて長い日記は続かないが、毎日を流したくない人。

学生でも社会人でも使えるよう、年齢や属性よりも「続けやすさを重視したい」「生活を少しずつ整えたい」という行動特性を軸に設計しています。

---

## 解決したい課題

- 日記を書こうとしても重くて続かない
- その日の出来事や気分が、記録されないまま流れてしまう
- 後から振り返ろうとしても、何を感じていたか思い出しにくい
- 生活を少しずつ改善したくても、ヒントになる記録が残っていない

このアプリでは、記録すること自体よりも、記録を見返して次の日を少し良くすることを目的にしています。

---

## プロダクト方針

### 1. 入力は短く、迷わせない

- 選択式と短文入力を中心にする
- 長文を書かなくても振り返れるようにする
- 毎日続けやすさを最優先にする

### 2. 見返して意味があることを重視する

- 一覧で流れを追える
- カレンダーで継続や偏りを確認できる
- 分析画面で傾向をざっくり掴める

### 3. 記録はあとから整えられる

- 過去日の編集ができる
- 日付変更ができる
- 削除ができる
- 集計は常に最新状態をもとに再計算する

---

## 現在できること

現時点の実装では、次の機能があります。

- テンプレートを選んで振り返りを作成
- 気分、カテゴリ、タグ、本文を記録
- 写真を添付
- 過去の記録を編集、削除
- お気に入り登録
- 履歴一覧で検索、絞り込み
- カレンダー表示で記録数を確認
- 分析画面で件数や傾向を確認
- 毎日のリマインド通知を設定

## 見返し機能の考え方

このアプリにおける「見返しやすい」は、単なる一覧表示ではありません。

目指している見返し体験:

- 日ごとの流れを追いやすい
- 気分の波が見える
- 続けられた日数が分かる
- 良かった日や崩れた日の傾向に気づける
- 次の数日を少し良くするヒントが得られる

---

## このアプリがやらないこと

少なくとも初期版では、以下を主役にしません。

- タスク管理
- 習慣トラッカー中心の設計
- 長文日記
- SNS 的な共有機能
- 情報を詰め込みすぎた重い分析ダッシュボード

このアプリは、セルフレビューの入口を軽くすることに価値があります。

## Notion CSV Import

Settings 画面から Notion の CSV を読み込んで、既存のレビュー形式に変換して保存できます。初版は API 連携ではなく、ローカルの CSV ファイルを選んで取り込む方式です。

### 想定列

必須列:
- `date`
- `template`

任意列:
- `category`
- `mood`
- `favorite`
- `action_tags`
- `state_tags`

テンプレート回答列:
- 既存テンプレートの `field key` を列名として使います
- 例: `title`, `memo`, `keep`, `problem`, `try`, `good1`, `good2`, `good3`, `start`, `stop`, `continue`

ヘッダーは一部の日本語名や英語別名も受け付けますが、いちばん安定するのは上のキー名です。

### 取り込み手順

1. Notion データベースを CSV でエクスポートします。
2. 必要なら CSV の列名をこの README の想定列に合わせます。
3. アプリの Settings を開きます。
4. `CSV Import` の `CSV を選ぶ` を押してファイルを選択します。
5. 取り込み結果の件数と、スキップされた行の理由を確認します。

### 変換ルール

- `template` は既存テンプレート ID またはテンプレート名に一致する必要があります。
- `category` が不明な場合は既定カテゴリに補正します。
- `mood` は `1` から `5`、または既存表示名に一致する値を受け付けます。不明な値は未設定になります。
- `action_tags` と `state_tags` はカンマ区切りで複数指定できます。
- CSV 内の新規タグはタグカタログへ追加してからレビューへ紐付けます。
- 写真は CSV インポート対象外です。

### スキップされるデータ

- `date` または `template` が欠けている行
- 日付として解釈できない `date`
- 既存テンプレートに一致しない `template`
- 回答列とタグがどちらも空の行
- 既に同じ日付のレビューが保存されている行
- 同じ CSV 内で日付が重複している後続行

### 保存処理との整合

- 既存の保存形式 `ReviewItem` に変換してから保存します。
- 日付重複の扱いは通常保存と同じく `1 日 1 レビュー` として扱い、重複行は追加せずスキップします。
- 既存のタグカタログと統合し、必要なタグだけ追加します。
