# 振り返りアプリ（仮称）

忙しい日でも短時間で記録でき、あとから見返して次の日の改善につなげられる軽量な振り返りアプリです。

「長い日記は続かない。でも何も残さないと毎日が流れてしまう」という感覚に対して、重すぎない入力と見返しやすさの両立を目指しています。

---

## コンセプト

このアプリは、次の3つを大切にしています。

- 軽いコストでさっと振り返れること
- あとから見返しやすいこと
- 日々を少しずつ改善していけること

### 想定ユーザー

忙しくて長い日記は続かないが、毎日を流したくない人。

学生でも社会人でも使えるよう、年齢や属性よりも「続けやすさを重視したい」「生活を少しずつ整えたい」という行動特性を軸に設計しています。

---

## 解決したい課題

- 日記を書こうとしても重くて続かない
- その日の出来事や気分が、記録されないまま流れてしまう
- 後から振り返ろうとしても、何を感じていたか思い出しにくい
- 生活を少しずつ改善したくても、ヒントになる記録が残っていない

このアプリでは、記録すること自体よりも、記録を見返して次の日を少し良くすることを目的にしています。

---

## プロダクト方針

### 1. 入力は短く、迷わせない

- 選択式と短文入力を中心にする
- 長文を書かなくても振り返れるようにする
- 毎日続けやすさを最優先にする

### 2. 見返して意味があることを重視する

- 一覧で流れを追える
- カレンダーで継続や偏りを確認できる
- 分析画面で傾向をざっくり掴める

### 3. 記録はあとから整えられる

- 過去日の編集ができる
- 日付変更ができる
- 削除ができる
- 集計は常に最新状態をもとに再計算する

---

## 現在できること

現時点の実装では、次の機能があります。

- テンプレートを選んで振り返りを作成
- 気分、カテゴリ、タグ、本文を記録
- 写真を添付
- 過去の記録を編集、削除
- お気に入り登録
- 履歴一覧で検索、絞り込み
- カレンダー表示で記録数を確認
- 分析画面で件数や傾向を確認
- 毎日のリマインド通知を設定

## 見返し機能の考え方

このアプリにおける「見返しやすい」は、単なる一覧表示ではありません。

目指している見返し体験:

- 日ごとの流れを追いやすい
- 気分の波が見える
- 続けられた日数が分かる
- 良かった日や崩れた日の傾向に気づける
- 次の数日を少し良くするヒントが得られる

---

## このアプリがやらないこと

少なくとも初期版では、以下を主役にしません。

- タスク管理
- 習慣トラッカー中心の設計
- 長文日記
- SNS 的な共有機能
- 情報を詰め込みすぎた重い分析ダッシュボード

このアプリは、セルフレビューの入口を軽くすることに価値があります。

## Notion CSV Import

Settings 画面から Notion の CSV を読み込んで、既存のレビュー形式に変換して保存できます。初版は API 連携ではなく、ローカルの CSV ファイルを選んで取り込む方式です。

### 想定列

必須列:
- `タイトル`
- `今日の気分`
- `日付`

実データ例:
- `始発帰りからの爆睡えりちゃんday, ☀, 2026/04/05`

### 取り込み手順

1. Notion データベースを CSV でエクスポートします。
2. アプリの Settings を開きます。
3. `Notion CSV Import` の `Notion CSV を取り込む` を押してファイルを選択します。
4. 取り込み結果の件数と、スキップされた行の理由を確認します。

### 変換ルール

- `タイトル` は既存レビューの `answers.title` に入ります。
- テンプレートは既定で `diary` を使います。
- `今日の気分` は既存の mood 数値へ変換します。
  - `☀` -> `5`
  - `☀, ☁` -> `4`
  - `☁` -> `3`
  - `☔` -> `2`
  - 不明値 -> `3`
- `日付` は `YYYY/MM/DD` と `YYYY-MM-DD` の両方を受け付けます。
- UTF-8 BOM 付き CSV でも読めます。

### 重複判定

- 完全重複の判定は `日付 + タイトル + 気分` ベースです。
- 同じ日付でもタイトルが違えば別レコードとして取り込みます。
- 同じ CSV を再インポートしても、同じデータは増えないようにしています。
- 取り込み元の識別として `notion-import` メタ情報を保持します。

### スキップ・エラー扱い

- `タイトル` が空
- `日付` が解釈できない
- 既に同じ Notion データが取り込まれている
- 同じ CSV 内で完全重複している

取り込み結果では以下を表示します。
- 読み込み件数
- 追加件数
- スキップ件数
- エラー件数
- 行番号つきの詳細メッセージ

### 保存処理との整合

- 既存の保存形式 `ReviewItem` に変換してから追記保存します。
- 既存データは消しません。
- 取り込み後は履歴、カレンダー、分析画面で再起動なしに参照できます。
