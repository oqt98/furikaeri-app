## Data safety 申告メモ

| データ | 収集/保存 | 保存先 | 共有 | 利用目的 | 削除方法 |
| --- | --- | --- | --- | --- | --- |
| ふりかえり本文 | あり | 端末内、Supabase DB | Supabase | アプリ機能、保存、表示、復元 | アプリ内削除、クラウド削除依頼 |
| 気分、タグ | あり | 端末内、Supabase DB | Supabase | アプリ機能、分析表示、復元 | アプリ内削除、クラウド削除依頼 |
| タグ | あり | 端末内、Supabase DB | Supabase | 記録整理、表示、復元 | アプリ内削除、クラウド削除依頼 |
| 写真、写真メモ | あり | 端末内、Supabase Storage / DB | Supabase | 写真付き記録、表示、復元 | アプリ内削除、クラウド削除依頼 |
| 通知リマインダー設定 | あり | 端末内、Supabase DB (`app_preferences`) | Supabase | 通知設定の保持 | アプリ内変更/削除、クラウド削除依頼 |
| 大切な日 | あり | 端末内のみ | なし | 一覧、ホーム、カレンダー表示 | 大切な日画面で個別削除 |
| テーマ、言語、オンボーディング状態 | あり | 端末内、Supabase DB (`app_preferences`) | Supabase | アプリ設定の保持 | アプリ内変更、クラウド削除依頼 |
| 匿名ユーザーID | あり | Supabase Auth | Supabase | 匿名認証、クラウド保存 | クラウド削除依頼 |

初回リリースでは、OpenAI などのAIサービスは利用しません。AI要約、Import / Export、Notion CSV import、JSON export / import は提供しません。
