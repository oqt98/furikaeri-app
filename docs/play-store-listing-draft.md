# Play Store 掲載文案

この文案は `Daynote - ふりかえり日記` の初回 Android リリース向けです。Google Play Console へ入力する前に、実際の公開範囲、スクリーンショット、プライバシーポリシーに合わせて最終確認してください。

## アプリ名

Daynote - ふりかえり日記

## 短い説明

気分とひとことで続ける、軽いふりかえり日記アプリ。

## 詳しい説明

Daynote は、毎日の出来事や気分を短く残して、あとから見返しやすくするためのふりかえり日記アプリです。

長い日記を書き続けるのが大変な日でも、気分と出来事だけで記録できます。必要なときだけ、タグ、写真、テンプレート質問を追加できます。誕生日や記念日などの大切な日も登録でき、ホームやカレンダーから見返せます。

主な機能:

- 気分とひとことで素早く記録
- 1日1件のふりかえりを記録
- 行動タグ、気分タグで整理
- 写真付き記録
- 履歴、検索、絞り込み
- カレンダーで日ごとの記録を確認
- 基本的なふりかえり分析
- 通知リマインダー
- 大切な日の登録、編集、削除、一覧表示
- テーマ、言語、オンボーディング、About

Daynote は、医療・心理診断を目的としたアプリではありません。毎日の記録を見返しやすくするための補助ツールです。

## 初回リリースに含めない機能

以下の機能は初回リリースには含めません。ストア説明やスクリーンショットにも表示しないでください。

- AI要約
- Import / Export
- Notion CSV import
- JSON export / import
- 課金

## スクリーンショット候補

1. ホーム画面
   - 今日の記録状況、最近のふりかえり、次に近い大切な日が分かる状態
2. 記録作成画面
   - 気分、ひとこと、保存が見える状態
3. 記録作成の詳細展開
   - タグ、テンプレート質問、写真を開いた状態
4. 履歴画面
   - 検索、フィルター、お気に入りが分かる状態
5. カレンダー画面
   - 日ごとの記録と大切な日が見える状態
6. 分析画面
   - 基本分析が見える状態
7. 大切な日画面
   - 大切な日の登録フォームと一覧が見える状態

## スクリーンショット内コピー案

- 気分とひとことで、今日を軽く残す
- タグや写真は、必要なときだけ
- 履歴とカレンダーで見返しやすい
- 1日1件のふりかえりを続ける
- 大切な日も忘れずに見返せる
