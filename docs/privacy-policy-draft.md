# プライバシーポリシー草案

この文書は `Daynote - ふりかえり日記` の初回 Android リリース向け草案です。公開前に「公開前に確定する項目」を埋めてから、公開ページへ掲載してください。

## 公開前に確定する項目

| 項目 | 人間が決める内容 | 現時点の扱い |
| --- | --- | --- |
| 運営者名 | 個人名、屋号、または法人名 | 未確定 |
| 連絡先 | 問い合わせを受けるメールアドレス | 未確定 |
| プライバシーポリシーURL | Google Play Console に登録する公開URL | 未確定 |
| 制定日 | 初回公開日、またはポリシー公開日 | 未確定 |
| クラウド保存データの削除依頼方法 | メール依頼、フォーム、アプリ内導線など | 初回公開前に運用手順を決める |

## 1. 取得する情報

本アプリは、ユーザーが入力または設定した以下の情報を扱います。

| 情報 | 内容 | 保存先 |
| --- | --- | --- |
| ふりかえり記録 | 日付、気分、カテゴリ、テンプレート回答、ひとこと、メモ、お気に入り | 端末内、Supabase DB |
| タグ | 行動タグ、気分タグ、タグの表示設定 | 端末内、Supabase DB |
| 写真 | ユーザーが記録に追加した写真、写真に付けたメモ | 端末内、Supabase Storage / DB |
| 通知リマインダー設定 | 通知のオン/オフ、通知時刻 | 端末内、必要に応じてSupabase DB |
| 大切な日 | 名前、日付、種類、毎年繰り返すかどうか、作成日時、更新日時 | 端末内のみ |
| アプリ設定 | テーマ、言語、オンボーディング状態など | 端末内 |
| 匿名ユーザーID | 匿名認証とクラウド保存に必要な識別子 | Supabase Auth |

## 2. 利用目的

取得した情報は、以下の目的で利用します。

- ふりかえり記録の保存、表示、編集、削除
- 履歴、カレンダー、基本分析画面での表示
- タグや写真を使った記録整理
- 大切な日の一覧表示、ホーム表示、カレンダー表示
- 通知リマインダーの設定と送信
- 端末変更時や再インストール時に記録を復元しやすくするためのクラウド保存
- アプリ設定の保存

## 3. クラウド保存

本アプリは、ふりかえり記録、タグ、写真、通知リマインダー設定などを Supabase 上に保存する場合があります。クラウド保存は、端末内データを復元しやすくするために利用します。

大切な日は、初回リリース時点では端末内に保存されます。Supabase同期対象ではありません。

## 4. AI要約について

初回リリースでは、生成AI要約機能は提供しません。日記本文やふりかえり内容をAI要約のために外部AIサービスへ送信する導線はありません。

## 5. Import / Export について

初回リリースでは、Import / Export、Notion CSV import、JSON export / import は提供しません。

## 6. 第三者提供と外部サービス

法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供しません。ただし、アプリ提供に必要な範囲で、以下の外部サービスを利用します。

| 外部サービス | 利用目的 |
| --- | --- |
| Supabase | 匿名認証、クラウド保存、写真保存 |

初回リリースでは、OpenAI などのAIサービスは利用しません。

## 7. データの削除

ユーザーは、アプリ内の設定画面から端末内のふりかえり記録を削除できます。大切な日は、大切な日画面から個別に削除できます。

クラウドに保存されたデータの削除依頼方法は、公開前に確定した連絡先または削除依頼手順に従って案内します。

## 8. 通知

本アプリは、ユーザーが通知リマインダーを有効にした場合に限り、ふりかえりを促す通知を送信します。通知は端末の設定から無効にできます。

大切な日には、初回リリース時点で個別の通知設定はありません。

## 9. お問い合わせ

本アプリに関するお問い合わせは、公開前に確定する連絡先までお願いします。

## 10. 改定

本プライバシーポリシーは、必要に応じて変更されることがあります。重要な変更がある場合は、アプリ内または公開ページ上でお知らせします。

## 11. 制定日

公開前に確定する制定日を記載します。
