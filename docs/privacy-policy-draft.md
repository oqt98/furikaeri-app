# プライバシーポリシー草案

この文書は `Daynote - ふりかえり日記` の初回 Android リリース向け草案です。公開前に、実際の運用者名、連絡先、公開URL、外部サービスを最終確認してください。

## 1. 取得する情報

本アプリは、ユーザーが入力した以下の情報を扱います。

- 日記、ふりかえり本文
- 気分、カテゴリ、タグ
- 写真、写真に付けたメモ
- お気に入り設定
- 大切な日の名前、日付、種類、毎年繰り返すかどうか、作成日時、更新日時
- 通知リマインダー設定
- テーマ、言語などのアプリ設定
- 匿名認証に必要なユーザー ID

## 2. 利用目的

取得した情報は、以下の目的で利用します。

- 日記、ふりかえり記録の保存と表示
- 履歴、カレンダー、基本分析画面での表示
- 大切な日の一覧表示、ホーム表示、カレンダー表示
- アプリ設定や通知設定の保存
- 端末変更時や再インストール時に記録を復元しやすくするためのクラウド保存

## 3. クラウド保存

本アプリは、記録内容、タグ、写真、設定情報を Supabase 上に保存する場合があります。クラウド保存は、端末内データを復元しやすくするために利用します。

大切な日は、初回リリース時点では端末内に保存されます。Supabase同期対象ではありません。

## 4. AI要約について

初回リリースでは、生成AI要約機能は提供しません。日記本文をAI要約のために外部AIサービスへ送信する導線はありません。

## 5. 第三者提供

法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供しません。ただし、アプリ提供に必要な範囲で、クラウド保存や認証などの外部サービスを利用します。

利用する外部サービス:

- Supabase

## 6. データの削除

ユーザーは、アプリ内の設定画面から端末内の記録を削除できます。大切な日は、大切な日画面から個別に削除できます。クラウドに保存されたデータの削除方法は、公開前に運用手順を確定します。

## 7. 通知

本アプリは、ユーザーが有効にした場合に限り、日記やふりかえりを促す通知を送信します。通知は端末の設定から無効にできます。

大切な日には、初回リリース時点で個別の通知設定はありません。
