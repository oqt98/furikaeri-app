# プライバシーポリシー草案

この文書は `Daynote - ふりかえり日記` の初回 Android リリースに向けた草案です。
公開前に、実際の運用者名、連絡先、プライバシーポリシー公開 URL、利用する外部サービスを確認して最終化してください。

## 1. 取得する情報

本アプリは、ユーザーが入力した以下の情報を扱います。

- 日記、ふりかえり本文
- 気分、カテゴリ、タグ
- 写真、写真に付けたメモ
- お気に入り設定
- 通知リマインダー設定
- テーマ、言語などのアプリ設定
- 匿名認証に必要なユーザー ID

## 2. 利用目的

取得した情報は、以下の目的で利用します。

- 日記、ふりかえり記録の保存と表示
- 履歴、カレンダー、分析画面での表示
- 週次 AI 要約の生成
- アプリ設定や通知設定の保存
- 再インストール時や端末変更時に記録を復元しやすくするためのクラウド保存

## 3. クラウド保存

本アプリは、記録内容、タグ、写真、設定情報を Supabase 上に保存する場合があります。
クラウド保存は、端末内のデータを復元しやすくするために利用します。

## 4. AI 要約

本アプリの週次 AI 要約機能では、ユーザーのふりかえり記録を backend 経由で AI サービスに送信し、要約を生成する場合があります。
AI 要約は、記録を見返しやすくするための補助機能です。

本アプリは、医療・心理診断、治療、助言を目的としたものではありません。

## 5. 第三者提供

法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供しません。
ただし、アプリ提供に必要な範囲で、クラウド保存、認証、AI 要約などの外部サービスを利用します。

利用する外部サービス:

- Supabase
- OpenAI API

## 6. データの削除

ユーザーは、アプリ内の設定画面から端末内の記録を削除できます。
クラウドに保存されたデータの削除方法は、公開前に運用手順を確定します。

## 7. 通知

本アプリは、ユーザーが有効にした場合に限り、日記やふりかえりを促す通知を送信します。
通知は端末の設定から無効にできます。
