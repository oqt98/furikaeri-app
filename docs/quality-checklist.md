# 品質確認チェックリスト

初回リリース前に、最低限ここは確認したい項目をまとめます。

## まず回すもの

- `npm run test`
- `npm run typecheck`
- `npm run lint`

注意:
- `typecheck` は通る状態を維持する

## 機能確認

- 記録作成
  - 入力して保存できる
  - 保存中に二重タップしても壊れない
  - クラウド同期失敗時に文言が出る
- 履歴
  - 一覧が表示される
  - 取得失敗時に再試行できる
  - お気に入り切り替えと削除で失敗時の文言が出る
- カレンダー
  - 保存済み記録が日付ごとに見える
- 分析
  - 記録ゼロ件の週で空状態が出る
  - 1-2件週で短い AI 要約の説明が出る
  - AI 要約失敗時に再試行できる
- 匿名開始
  - 起動時に Supabase セッションが確保される
- クラウド保存
  - create / update / list / detail / favorite / delete が最低限動く
- AI要約
  - Supabase Edge Function 経由で呼ばれる
  - API key をアプリ側に持たない

## Android 実機で見るポイント

- 起動直後に落ちない
- 記録作成から保存まで片手操作で進められる
- 画像付き記録が保存できる
- 通信オフ時にローカル保存中心の画面が極端に壊れない
- AI 要約ボタンの状態が分かりやすい
- 戻る操作で入力中データが意図せず消えない

## E2E / 手動確認のおすすめ順

1. 記録作成 -> 保存 -> 履歴確認
2. 履歴 -> 分析 -> 設定遷移
3. AI 要約の生成
4. 通信失敗時の文言確認

## 未対応・要注意

- smoke test の安定化
- Supabase 実環境での end-to-end 確認
- Android 実機でのネットワーク不安定時確認
