# 品質確認チェックリスト

初回リリース前に最低限確認したい項目です。

## コマンド

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build:web`

## 機能確認

- 記録作成
  - 気分とひとことで保存できる
  - 同じ日に2件目を作ろうとしたとき、既存記録の更新扱いになる
  - 別日分の記録を作成できる
  - 保存中に連打しても壊れない
  - クラウド同期失敗時にユーザー向け文言が出る
- 履歴
  - 一覧が表示される
  - 検索、絞り込み、お気に入り切り替えが動く
  - 詳細、編集、削除が動く
- カレンダー
  - 保存済み記録が日付ごとに見える
  - 大切な日が日付ごとに見える
- 分析
  - 記録ゼロ件の空状態が出る
  - 基本分析が表示される
  - AI要約カードや生成ボタンが出ない
- タグ
  - 行動タグ、気分タグを付けられる
  - タグ管理画面に遷移できる
- 写真
  - 写真付き記録を保存できる
  - 写真削除が動く
- 通知
  - リマインダーをオン / オフできる
  - 時刻を変更できる
- 大切な日
  - 新規登録できる
  - 編集できる
  - 削除できる
  - 一覧表示できる
  - ホームとカレンダーに反映される
  - アプリ再起動後も保持される
  - 初回リリースでは個別通知が表示されない
  - 初回リリースではSupabase復元対象として扱われない
- 設定 / サイドメニュー
  - テーマ、言語、オンボーディング、About、大切な日に到達できる
  - インポート / エクスポート導線が出ない

## Android 実機で見るポイント

- 起動直後に落ちない
- 記録作成から保存まで片手操作で進められる
- 画像付き記録が保存できる
- 大切な日の登録、編集、削除ができる
- 通信オフ時にローカル保存中心の画面が極端に壊れない
- 戻る操作で入力中データが意図せず消えない

## 未対応の要注意項目

- Supabase 実環境での end-to-end 確認
- Android 実機でのネットワーク不安定時確認
- Play Store 申告と実際のデータ利用の突き合わせ
