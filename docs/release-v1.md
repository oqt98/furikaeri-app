# 初回リリース方針

このメモは、`Daynote - ふりかえり日記` の初回 Android リリースで何を含めるかを固定するためのものです。

## 前提

- リリース対象は Android のみ
- Google Play 公開を想定
- backend 基盤は Supabase
- 認証は匿名開始を基本にする
- 入力の速さと続けやすさを優先する

## 初回リリースに含める機能

- 日次記録
- 1日1件のふりかえり
- 履歴
- カレンダー
- 基本分析
- タグ
- 写真
- 通知リマインダー
- テーマ / 言語 / オンボーディング / About
- Supabase Auth / Database / Storage 連携

## 初回リリースに含めない機能

- 週次AI要約
- AI要約生成ボタン
- Supabase Edge Function の週次AI要約をアプリ上から呼ぶ導線
- Notion CSV import
- JSON export / import
- インポート / エクスポート画面への導線
- iOS 公開
- 課金
- 高度な週次比較や有料分析

## 実装判断

- 同じユーザーの同じ日付は1件まで保存する
- 別日分の記録は作成できる
- 初回公開では、実装済みでもMVP外の導線はユーザーに見せない
- README と docs では、初回リリースに含まれるものと後続候補を混ぜて書かない

## 後続候補

- AI要約
- データのインポート / エクスポート
- 正式アカウント連携
- より詳しい分析
- iOS 公開
